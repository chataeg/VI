1인으로 제작한 1인칭 FPS 게임입니다.

개발 기간 : 2024.06.07 ~ 2024.07.31 (2달) 


# 게임의 목표

레벨에 설치되어 있는 타겟들을 쏴 맞혀 쓰러트리고 훈련을 종료합니다.

# 게임의 조작법

WASD와 스페이스바 로 캐릭터를 조작합니다.

1번, 2번 키(키패드 X)로 주운 무기를 변경 할 수 있습니다.

좌클릭으로 총을 쏘고, 우클릭으로 조준합니다.
R 키로 재장전을 합니다.

V키를 눌러 총을 바닥에 떨어트릴 수 있습니다.
